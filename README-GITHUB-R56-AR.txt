تدارُك v24 R56 — حزمة GitHub Pages الجاهزة للنشر

طريقة الرفع:
1) فك ضغط هذا الملف على جهازك.
2) افتح مستودع GitHub الخاص بالموقع.
3) ارفع جميع الملفات الموجودة داخل المجلد إلى جذر المستودع (وليس ملف ZIP نفسه).
4) تأكد أن index.html موجود في الجذر.
5) من Settings > Pages اختر Deploy from a branch، ثم اختر الفرع main والمجلد /(root).

مهم:
- هذه حزمة النشر فقط، بدون ملفات QA والتوثيق الداخلي.
- الإصدار يتضمن 8 اختيارات ألوان. تم ضبط أخضر «مِشكاة» على #173B39 مطابقًا تقريبًا للمرجع المرسل، مع وضع ليلي أخضر غامق متناسق، وكاش PWA محدث إلى R56.
