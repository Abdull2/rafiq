تدارُك R39 — رفع GitHub Pages

1) ارفع جميع ملفات حزمة R39 إلى جذر مستودع Abdull2/rafiq مع الاستبدال.
2) انتظر اكتمال GitHub Pages، ثم أغلق تدارُك وافتحه من جديد حتى يلتقط Service Worker R39.
3) اختبر من هاتف حقيقي: القرآن ← "فتح التفسير الميسر كاملًا"، ثم زر "فتح القارئ الرسمي الكامل". يجب أن يفتح موقع مجمع الملك فهد بدل شاشة iframe فارغة.
4) اختبر أيضًا: العلم ← التفسير وعلوم القرآن ← التفسير الميسر، ثم الفتح الكامل.
5) تحقق من زر الرجوع بعد فتح الموقع الرسمي ومن الوضعين الداكن/الفاتح.
6) لا تحذف أي ملفات بيانات مستخدم؛ بيانات المستخدم محلية على أجهزتهم وليست في GitHub.

لا تحتاج AAB جديدًا لهذا الإصلاح؛ هو Web/PWA. Chrome Extension يحتاج حزمة منفصلة فقط إذا أردت نشر R39 هناك.
