تدارُك R25 — المختصر في التفسير

ارفع محتويات هذه الحزمة فوق ملفات الريبو الحالي مع Replace للملفات الموجودة.

العمل الفوري بعد الرفع:
- داخل المصحف: اختر آية ثم اضغط «التفسير».
- ستظهر لوحة داخل تدارُك بالآية والمرجع وزر يفتح تفسير نفس الآية في المصدر الرسمي.

مهم:
- عرض نص «المختصر» نفسه داخل تدارُك غير مفعّل افتراضيًا لأن API الرسمي يحتاج Bearer Token، ولا يجوز وضعه في GitHub العام.
- ملفات integrations/mokhtasar-worker/ جاهزة لعمل Proxy آمن بعد الحصول على Token رسمي.
- لا تضع أي Token داخل app/tafsir-config.js. هذا الملف عام.
