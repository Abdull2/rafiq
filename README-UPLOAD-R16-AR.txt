أهم التغييرات:
1) AI_HANDOFF.md كامل ومحفوظ + قاعدة صريحة: ممنوع حذفه/اختصاره/استبعاده، وكل جلسة لاحقة تضيف الشات والتغييرات والاختبارات.
2) المصحف: Fullscreen أقوى — طلب Fullscreen على مستوى الصفحة + CSS fallback + إخفاء الأدوات تلقائيًا.
3) الصلاة/الوقت/الموقع: بطاقة واضحة في الرئيسية. عند الضغط يفتح إعداد الصلاة والموقع؛ Android/المتصفح يطلب إذن الموقع؛ التوقيت يؤخذ تلقائيًا من الهاتف؛ الإحداثيات تبقى محليًا.
4) الصفحة الرئيسية: Hierarchy جديدة وأهدأ؛ الصلاة في الأعلى، ثم القرآن/الأذكار، ثم العلم/الفقه/التزكية/ارتقِ.
5) محفوظاتي: إزالة الفقاعة العددية الكبيرة واستبدالها بنقطة صغيرة؛ العدد يظل في aria/title.
6) Service Worker: cache R16 وتفعيل التحديث الجديد بسرعة أكبر بعد GitHub Pages.

هل يحتاج AAB جديد؟
- لا، هذه تغييرات Web/PWA داخل الموقع، وبالتالي TWA المثبت من Google Play يقرأها من GitHub Pages.
- AAB جديد مطلوب فقط إذا غيّرت Android shell/native/package/permissions/target SDK أو ما شابه.

بعد الرفع:
- انتظر GitHub Pages حتى ينشر التغييرات.
- أغلق التطبيق وافتحه. Service Worker R16 يفحص التحديث ويُفعّله؛ قد يحدث Reload واحد عند انتقال الـcontroller.
- اختبر على Android الحقيقي:
  أ) الصفحة الرئيسية الجديدة.
  ب) اضغط «تفعيل المواقيت» واسمح بالموقع.
  ج) تأكد أن الصلاة القادمة تظهر وأن الإعدادات تعرض Timezone الجهاز.
  د) افتح المصحف > صفحة > زر Fullscreen. الأدوات تختفي تلقائيًا؛ اضغط مساحة فارغة لإظهارها والخروج.
  هـ) احفظ عنصرًا وتأكد أن أعلى محفوظاتي تظهر نقطة صغيرة فقط.
