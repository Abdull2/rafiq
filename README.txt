تطبيق دروس الشيخ محمد عبدالعظيم الباز
=====================================

الملف الوحيد الذي ستعدّله باستمرار هو:  content.json

--------------------------------------------------
كيف تضيف سلسلة أو درسًا؟
--------------------------------------------------
افتح content.json وستجد لكل سلسلة قالبًا كهذا:

{
 "id": "usool3",
 "cat": "aqeedah",
 "name": "كتاب الأصول الثلاثة",
 "desc": "",
 "base": "https://archive.org/download/usool3-albaz/",
 "lessons": [
   { "t": "الدرس الأول", "f": "001.mp3" },
   { "t": "الدرس الثاني", "f": "002.mp3" }
 ]
}

base    : رابط مجلد العنصر على archive.org (بشرطة / في آخره)
lessons : قائمة الدروس، t = عنوان الدرس، f = اسم الملف
        : ويمكن بدل f وضع "url" برابط كامل إن كان الملف في مكان آخر

السلسلة التي لا دروس لها تظهر في التطبيق مكتوبًا عليها «قريبًا».
بمجرد رفع الملفات وتحديث content.json على GitHub، يراها كل المستخدمين
فورًا بدون تحديث التطبيق (ملف المحتوى يُجلب من الشبكة أولًا).

--------------------------------------------------
رفع الصوتيات
--------------------------------------------------
لكل سلسلة عنصر مستقل على archive.org، وسمِّ ملفاتها 001.mp3 وهكذا.
اضغط الملفات قبل الرفع لتوفير المساحة والباقة:
   ffmpeg -i in.mp3 -ac 1 -b:a 48k out.mp3
(٤٨kbps يكفي للدروس الكلامية تمامًا)

--------------------------------------------------
النشر
--------------------------------------------------
1. ارفع ملفات هذا المجلد على مستودع GitHub جديد
2. Settings → Pages → main / (root)
3. افتح الرابط من الموبايل → إضافة إلى الشاشة الرئيسية
4. للنشر على Google Play: pwabuilder.com → Package for stores → Android

--------------------------------------------------
مزايا التطبيق
--------------------------------------------------
- تصنيف الدروس بالأقسام (عقيدة، تفسير، حديث، فقه، سيرة، رقائق، قرآن، خطب)
- «أكمل الاستماع» يعيدك لآخر نقطة توقفت عندها
- تعليم الدرس كمسموع ونسبة إنجاز لكل سلسلة
- تحميل درس أو سلسلة كاملة للاستماع بدون إنترنت
- تدوين فائدة أثناء الاستماع مع توقيتها، والضغط عليها يعيدك للحظتها
- بحث في السلاسل والدروس، وحفظ السلاسل المفضّلة
- سرعة التشغيل حتى ٢×، مؤقّت نوم، تشغيل في الخلفية وعلى شاشة القفل
