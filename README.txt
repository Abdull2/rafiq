رفيق يومك — حزمة التطبيق الجاهزة للنشر
=====================================

المحتويات:
  index.html            الشاشة الرئيسية (محاسبة + صلاة + أذكار + ورد + سجل)
  tasbih.html           المسبحة الكاملة
  manifest.webmanifest  بيانات التطبيق (الاسم، الأيقونة، لون الواجهة)
  sw.js                 يجعل التطبيق يعمل بدون إنترنت
  icon-*.png            أيقونات التطبيق
  icon-1024.png         لصفحة المتجر (غير مستخدمة داخل التطبيق)

مهم: لا تغيّر أسماء الملفات، وارفع المجلد كاملًا.

=====================================
الخطوة ١ — النشر على GitHub Pages (مجاني)
=====================================
1. أنشئ حسابًا على github.com
2. New repository → الاسم: rafiq → Public → Create
3. "uploading an existing file" → اسحب كل ملفات هذا المجلد → Commit
4. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
5. انتظر دقيقتين، سيظهر الرابط:
   https://اسم-حسابك.github.io/rafiq/

=====================================
الخطوة ٢ — التثبيت على الموبايل
=====================================
آيفون: افتح الرابط في Safari → زر المشاركة → إضافة إلى الشاشة الرئيسية
أندرويد: افتح الرابط في Chrome → القائمة → تثبيت التطبيق

=====================================
الخطوة ٣ — النشر على Google Play (اختياري)
=====================================
1. ادخل pwabuilder.com والصق رابط موقعك
2. اضغط Package for stores → Android
3. حمّل الملف الناتج (.aab) — هذا هو تطبيقك
4. اشترك في Google Play Console (٢٥ دولار مرة واحدة مدى الحياة)
5. Create app → ارفع ملف .aab → املأ الوصف وارفع icon-1024.png
6. المراجعة تستغرق أيامًا قليلة ثم ينشر

ملاحظة عن آيفون: نشر تطبيق على App Store يتطلب جهاز Mac
واشتراكًا سنويًا ٩٩ دولارًا. طريقة "إضافة إلى الشاشة الرئيسية"
تعطي نفس النتيجة عمليًا وبدون تكلفة.

--------------------------------------------------
قسم «علاج القلوب»  (qalb.html + qalb.json)
--------------------------------------------------
كل المحتوى في ملف qalb.json، وتعديله لا يحتاج لمس الكود.
قالب المشكلة الواحدة:

{
 "id": "shahwa",
 "name": "الشَّهْوَة",
 "sub": "سطر واحد يصف المشكلة",
 "icon": "◐",
 "def": "تعريف مختصر",
 "causes": ["السبب الأول", "السبب الثاني"],
 "cure": [
   { "t": "عنوان العلاج", "d": "شرحه", "track": 1 }
 ],
 "proof": "آية أو حديث",
 "note": "تنبيه يظهر في صندوق بارز (اختياري)"
}

track: 1  = يظهر له مربع متابعة يومية وسلسلة أيام
track: 0  = إرشاد فقط بلا متابعة

المستخدم يرى أي تعديل فورًا (الملف يُجلب من الشبكة أولًا).
راجِع النصوص مع الشيخ قبل النشر، وأضف مراجعها إن أردت.
