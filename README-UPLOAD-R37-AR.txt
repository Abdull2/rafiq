تدارُك R37 — رفع GitHub Pages

1) ارفع ملفات حزمة GitHub Update إلى جذر مستودع Abdull2/rafiq مع الاستبدال.
2) إذا كان الملف القديم `tafsir-config.js` ما زال موجودًا في المستودع، احذفه يدويًا. R37 لا يستخدم المختصر ولا هذا الملف.
3) لا تحذف ملفات بيانات المستخدم؛ بيانات المستخدم محلية على أجهزتهم وليست في GitHub.
4) انتظر GitHub Pages ثم أغلق تدارُك وافتحه من جديد حتى يلتقط Service Worker R37.
5) راجع على هاتف حقيقي: الصفحة الرئيسية، خريطة العلم، التفسير الميسر، بطاقة مصاحف الروايات، الوضع الداكن/الفاتح.

لا تحتاج AAB جديدًا لهذه التغييرات؛ هي Web/PWA. Chrome Extension يحتاج حزمة منفصلة إذا أردت نشر R37 هناك.
