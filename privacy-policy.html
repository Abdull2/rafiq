سياسة الخصوصية — رفيق يومك

آخر تحديث: 18 أغسطس 2026
إضافة «رفيق يومك» لا تبيع بيانات المستخدم ولا تستخدمها للإعلانات أو التتبع أو تحديد الجدارة الائتمانية. تُخزَّن بيانات الاستخدام الشخصية محليًا على جهاز المستخدم، ولا تُرسل إلى خوادم المطور.

1. البيانات التي تتعامل معها الإضافة

تتعامل الإضافة مع البيانات التالية فقط لتقديم وظائفها للمستخدم:

  • المحتوى الذي يختاره المستخدم من صفحات الويب: عند تحديد نص ثم اختيار أمر «رفيق يومك» من قائمة الزر الأيمن، تستخدم الإضافة النص المحدد لتنفيذ البحث داخل الإضافة أو لحفظه في «دفتر رفيق».
  • عنوان الصفحة ورابطها: عند اختيار المستخدم حفظ نص محدد في «دفتر رفيق»، يمكن حفظ عنوان الصفحة ورابطها مع النص محليًا حتى يعرف المستخدم مصدر ملاحظته.
  • الموقع الجغرافي: إذا ضغط المستخدم زر تحديد الموقع ووافق على إذن الموقع، تُستخدم إحداثياته لحساب مواقيت الصلاة واتجاه القبلة، وتُخزَّن محليًا على جهازه.
  • بيانات يدخلها المستخدم داخل الإضافة: مثل تقييمات المحاسبة، السجل اليومي، التفضيلات، المهام، الملاحظات وبيانات «دفتر رفيق».

2. كيفية استخدام البيانات

تُستخدم البيانات فقط لتشغيل الميزات التي طلبها المستخدم، مثل البحث في النص المحدد، حفظ الملاحظات، استرجاعها، حساب مواقيت الصلاة، عرض التنبيهات الاختيارية وحفظ إعدادات الإضافة.

3. التخزين والاحتفاظ

تُخزَّن بيانات المستخدم في مساحة التخزين المحلية الخاصة بمتصفح Chrome على جهاز المستخدم. لا توجد حسابات مستخدمين أو قاعدة بيانات سحابية لدى المطور لهذه البيانات. تبقى البيانات محليًا إلى أن يحذفها المستخدم أو يزيل الإضافة/بياناتها من المتصفح.

4. الاتصال بخدمة الدرر السنية

تتضمن الإضافة تكاملًا مع dorar.net لعرض نتائج حديثية عند فتح بعض صفحات «أسماء الله الحسنى». في هذه الحالة ترسل الإضافة اسمًا دينيًا محددًا من محتوى الإضافة إلى واجهة الدرر السنية للحصول على النتائج. لا ترسل الإضافة إلى الدرر السنية ملاحظات المستخدم، أو النصوص التي حفظها من صفحات الويب، أو سجله اليومي، أو إحداثيات موقعه.

كما هو الحال في أي اتصال ويب مباشر، قد تستقبل الخدمة الخارجية بيانات اتصال تقنية اعتيادية مثل عنوان IP وفقًا لسياساتها الخاصة.

5. مشاركة البيانات وبيعها

لا يبيع المطور بيانات المستخدم، ولا ينقلها إلى وسطاء بيانات أو منصات إعلانية، ولا يستخدمها للإعلانات المخصصة أو لأغراض الإقراض أو تحديد الجدارة الائتمانية. ولا تُشارك بيانات المستخدم الشخصية مع أطراف ثالثة لتقديم ميزات الإضافة.

6. الأذونات المستخدمة

  • sidePanel — لعرض «رفيق يومك» في اللوحة الجانبية.
  • activeTab — للتعامل مع التبويب الحالي في سياق الإجراء الذي يطلبه المستخدم.
  • contextMenus — لإضافة أوامر البحث والحفظ للنص الذي يحدده المستخدم.
  • storage — لحفظ إعدادات وبيانات المستخدم محليًا.
  • geolocation — اختياري، لحساب مواقيت الصلاة والقبلة بعد طلب المستخدم.
  • alarms — لتحديث حالة مواقيت الصلاة بشكل دوري.
  • notifications — إذن اختياري لإشعارات الصلاة إذا فعّله المستخدم.
  • https://dorar.net/* — لجلب النتائج الحديثية من الدرر السنية.

7. الأمان والحد من الاستخدام

تقتصر معالجة البيانات على ما يلزم لتشغيل الوظائف المعلنة للمستخدم. لا تستخدم الإضافة كودًا مستضافًا عن بُعد، ولا تحمّل شيفرات تنفيذية من خوادم خارجية. وتلتزم الإضافة بمتطلبات الاستخدام المحدود لبيانات المستخدم في Chrome Web Store.

8. تحكم المستخدم وحذف البيانات

يمكن للمستخدم حذف الملاحظات والبيانات التي توفر الإضافة واجهة لحذفها، أو حذف جميع بيانات الإضافة من إعدادات Chrome، أو إزالة الإضافة. ولأن البيانات الشخصية الأساسية محفوظة محليًا، فلا توجد لدى المطور نسخة خادمية منها.

9. التغييرات على السياسة

إذا تغيرت طريقة تعامل الإضافة مع البيانات، سيتم تحديث هذه السياسة وتاريخ آخر تحديث بما يعكس الممارسات الفعلية.

Privacy Policy — Rafiq Yomak

Last updated: August 18, 2026

Rafiq Yomak does not sell user data, use it for advertising or tracking, or use it for creditworthiness or lending purposes. Personal usage data is stored locally on the user's device and is not sent to the developer's servers.

Data handled by the extension

  • User-selected website content: when the user selects text and explicitly chooses a Rafiq context-menu action, the selected text is used for an in-extension search or saved to the local notebook.
  • Page title and URL: when the user explicitly saves selected text to the notebook, the page title and URL may also be stored locally as the source of the note.
  • Location: only after the user requests geolocation and grants permission, coordinates are used for prayer-time and Qibla calculations and stored locally.
  • User-entered extension data: including daily tracking, preferences, tasks, notes, and notebook entries.

Third-party service

The extension connects to dorar.net to retrieve hadith results when certain built-in “Names of Allah” details are opened. The request contains a built-in religious name used as the search term. The extension does not send the user's saved notes, selected website text, daily tracking data, or geolocation coordinates to Dorar. Like any direct web request, the external service may receive ordinary connection metadata such as the user's IP address under its own policies.

Sharing and retention

User data is not sold or transferred to advertising platforms or data brokers. Personal extension data is stored locally in Chrome storage and remains there until the user deletes it, clears the extension's data, or removes the extension.

Permissions

The extension uses sidePanel, activeTab, contextMenus, storage, geolocation, and alarms, with optional notifications, plus host access to https://dorar.net/* for the hadith-results feature.

Limited use

Data is handled only as necessary to provide the extension's disclosed user-facing features. The extension does not execute remotely hosted code and complies with the Chrome Web Store User Data Policy's Limited Use requirements.
